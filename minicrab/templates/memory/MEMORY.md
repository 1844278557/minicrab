## Entry Format

- Keep one memory per bullet.
- Use `[rule][YYYY-MM-DD]` under Business Rules.
- Use `[decision][YYYY-MM-DD]` under Project Decisions.
- Use `[lesson][YYYY-MM-DD]` under Lessons Learned.
- Use `[info][YYYY-MM-DD]` under Important External Information.
- Update existing bullets instead of adding duplicates or conflicting entries.

## Do Not Store Here

- User identity, preferences, personal facts, or behavior requirements; put those in USER.md.
- Temporary chat, raw tool output, current task progress, or full document contents.
- Uploaded documents themselves; index those through RAG when the user wants document Q&A.
